## 🚀 Proyectos Incluidos

### 1. 🛒 Análisis de Ventas y Rendimiento de E-commerce
* **Archivo:** `01_ecommerce_sales_analysis.ipynb`
* **Descripción:** Análisis exploratorio de transacciones de una tienda online para evaluar ingresos por categoría, distribución geográfica y métricas operativas.
* **Tecnologías:** Python, Pandas, NumPy, Matplotlib.
* **Hallazgos Clave:**
  * Generación y limpieza de datasets simulados de ventas multirregionales (Latinoamérica).
  * Agregación de datos por categoría para identificar las líneas de productos más rentables.
  * Visualización de ingresos totales mediante gráficos de barras interactivos.
